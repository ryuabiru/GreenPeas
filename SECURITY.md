# Security Policy

## Reporting a Vulnerability

Do not disclose suspected security vulnerabilities in a public GitHub Issue.
Use **Report a vulnerability** on the repository's Security tab to submit a private report. If that option is unavailable, open a GitHub Issue asking for a private reporting channel without including vulnerability details.

In a private report, include:

- A description of the vulnerability and its potential impact.
- Reproduction steps or a minimal proof of concept.
- The affected GreenPeas version and platform.
- Any suggested mitigation, if available.

Do not include real DNA sequences, credentials, personal information, or other
sensitive data. Use synthetic or minimized test data whenever possible.

Please allow time to investigate and prepare a fix before publishing details.
