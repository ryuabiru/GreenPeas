# GreenPeas ユーザーガイド

[English](USER_GUIDE.md) · [日本語 README](../README_ja.md)

GreenPeasは、DNA配列の閲覧・編集、アノテーションや制限酵素サイトの確認、シーケンス結果の比較、クローニング操作を行うデスクトップアプリです。現在のベータ版では、画面のボタン名は英語で表示されます。

## はじめに

1. [公式Releasesページ](https://github.com/ryuabiru/GreenPeas/releases)からOSに合う版をダウンロードします。Windows `x64`版にはNSIS形式の`-setup.exe`とMSI形式があります。どちらも同じアプリをインストールし、個人で使う場合はセットアップEXEが分かりやすい選択です。
2. GreenPeasを起動し、**Open Sequence File**またはサイドバーの**Open**で既存ファイルを開きます。**New Sequence** / **New**で新しい配列も作れます。対応ファイルはウィンドウへドラッグ＆ドロップできます。
3. サイドバーの**Sequences**から配列を選び、**Sequence**と**Map**タブで確認します。アラインメント結果がある配列には**Alignment**タブも表示されます。
4. 作業中の配列を保存するには**Save**を押します。新規配列は保存先の指定が必要です。形式を指定してコピーを作るには**Export…**を使います。

配列ファイルは手元のPCに保存されます。このベータ版は配列をアップロードしません。重要な実験データは別途バックアップしてください。

## 対応形式と保存

| 形式 | 開く | 保存・書き出し | 内容 |
| --- | --- | --- | --- |
| GreenPeas `.gp` | 可 | 可 | アラインメントやトレースを含むGreenPeasの作業データを保持します。作業を続ける場合に適しています。 |
| GenBank `.gb`, `.gbk` | 可 | 可 | 配列、アノテーション、プライマー、トポロジーを保持します。 |
| FASTA `.fa`, `.fasta` | 可 | 可 | 配列のみ。アノテーションとプライマーは含まれません。 |
| SnapGene `.dna` | 可 | 不可 | 読み込んだ後、**Save As…**または**Export…**でGreenPeas形式やGenBank形式のコピーを作れます。 |
| ABIトレース `.ab1` | 可 | 不可 | アラインメントと併せてトレースを確認できます。GreenPeas固有のトレースデータは`.gp`で保存します。 |

**Save**は、データを保持できる場合は現在の作業ファイル形式を使います。その形式では保持できないデータがある場合は、適切な形式の選択を求めます。**Export… → Export GenBank**は配列・アノテーション・プライマー、**Export FASTA**は配列のみ、**Export GreenPeas copy**はGreenPeasの作業データを書き出します。書き出したコピーは現在の作業ファイルを置き換えません。インポートした元ファイルは別に残しておくと安心です。

## 配列を見る・編集する

- **Sequence**には塩基配列とアノテーション、プライマー、制限酵素サイトが表示されます。範囲を選択すると、上部に位置・長さ・推定Tmが表示されます。ツールバーや右クリックメニューからコピー、切り取り、削除、逆相補配列への変換ができます。
- **Map**ではアノテーション、プライマー、制限酵素サイトを図として確認できます。アノテーションやプライマーをクリックするとその位置を選択し、ダブルクリックすると編集できます。ビュー上部の**Linear / Circular**で表示の基になるトポロジーを切り替えます。
- **Topology: Linear / Circular**は配列のトポロジー設定です。**Enzyme Filter**を使うと、切断回数によって表示する制限酵素サイトを絞れます。
- **Search**またはWindowsの`Ctrl+F`（macOSでは`Cmd+F`）で配列を検索できます。**DNA**と**Protein**を切り替え、矢印またはEnterで一致箇所を移動します。
- **Paste**は選択位置に配列を挿入します。隣のメニューの**Paste as RC**は逆相補配列として貼り付けます。編集内容は確認画面に表示され、**Undo** / **Redo**も使えます。

## アノテーションとプライマー

**Sequence**で塩基の範囲を選び、**Add Feature**を押します。名前、座標、種類、向き・形、色を設定できます。既存のアノテーションは編集画面から更新・削除できます。追加した内容は配列ビューとマップに表示されます。

プライマーは**Primers → Register Primer…**、または右クリックの**Register Primer**から登録します。名前と5′→3′の配列、Forward / Reverseを指定し、結合位置のプレビューを確認して保存します。プレビューには利用できる場合、ミスマッチやテールも表示されます。マップ上のプライマーをダブルクリックすると編集できます。

## 制限酵素とクローニング

**Enzymes → Manage Enzymes…**で**Master Library**を閲覧し、**Enzyme Sets**を作成したり、**Register New**から酵素を追加したりできます。Enzymesメニューには**Import SnapGene List…**もあります。制限酵素サイトは配列ビューとマップに表示され、**Enzyme Filter**で表示数を調整できます。

断片の操作では、**Sequence**で制限酵素サイトのマーカーから選択を始め、目的の末端まで範囲を広げて**Cut** / **Copy DNA**を使います。酵素マーカーから始めた選択には断片情報が付きます。通常の塩基選択をコピーした場合はDNAテキストです。生物学的な断片を対象配列へ貼り付ける場合、**Smart Ligation Preview**が末端の状態を示し、不適合なら警告します。内容を確認してから**Apply Ligation**を選んでください。通常の塩基配列を貼り付ける操作も使えます。複雑な作業の前には、GreenPeas固有のデータを保持できる`.gp`形式で保存しておくとよいでしょう。

## シーケンス結果を比較する

参照配列を開き、**Run Alignment**で比較するサンプルを1つ以上選びます。上記の対応形式を選択でき、`.ab1`も利用できます。アラインメントに成功すると**Alignment**タブが開き、差分やAB1トレースを確認できます。結果が表示されている状態では、**Add Alignment Sample**でサンプルを追加できます。アラインメントできないファイルは通知され、空のトラックとしては追加されません。結果やトレースを保持するには`.gp`で保存します。

試用できる[合成アラインメントサンプル](../test-data/alignment-samples)をリポジトリに用意しています。

## Windowsの主なショートカット

| 操作 | キー |
| --- | --- |
| 新規作成 / 開く / 保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` |
| 新しいウィンドウで開く | `Ctrl+Shift+O` |
| 元に戻す / やり直す | `Ctrl+Z` / `Ctrl+Shift+Z` |
| コピー / 貼り付け / 逆相補として貼り付け | `Ctrl+C` / `Ctrl+V` / `Ctrl+Shift+V` |
| 選択したDNAをアミノ酸配列としてコピー | `Ctrl+Shift+C` |
| 検索 | `Ctrl+F` |
| Sequence / Map / Alignment | `Ctrl+1` / `Ctrl+2` / `Ctrl+3` |
| プライマー登録 / 制限酵素管理 | `Ctrl+Shift+P` / `Ctrl+E` |

macOSでは`Ctrl`の代わりに`Cmd`を使います。利用できるショートカットはアプリのメニューでも確認できます。

## 表示設定と問題の報告

サイドバー上部の太陽・月のボタンでライトテーマとダークテーマを切り替えられます。サイドバーの**Settings**から表示設定を変更できます。**Help → About GreenPeas**にはアプリ情報があります。

問題の報告にはサイドバーのバグ報告ボタンか[GitHub Issues](https://github.com/ryuabiru/GreenPeas/issues)を利用してください。アプリが作る報告は下書きで、自動送信されません。公開前に、DNA配列、ローカルファイルパス、個人情報が含まれないか確認してください。脆弱性は[非公開の報告手順](../SECURITY.md)を利用してください。
